# ⚡ Гайд по Vibe-кодингу в Tawagram

> **Vibe-coding (Вайб-кодинг)** — это стиль разработки, когда ты не копаешься часами в дебрях пяти миллионов строк чужого C++ кода, а строишь крутые фичи на чистом кайфе и идеях, общаясь с нейронкой (ChatGPT, Claude, Cursor, Antigravity) на обычном человеческом языке.

Этот гайд покажет, как устроен **Tawagram**, куда смотреть и как быстро пилить любые свои задумки за считанные минуты.

---

## 🗺️ Карта клиента (Куда пинать нейронку)

Если ты хочешь попросить ИИ добавить новую фичу, покажи ему эту шпаргалку:

| Твоя идея | Где это живет в коде | Что делает |
|---|---|---|
| **Новые команды (`.команда`), автозамены текста** | `tdata/plugins/*.py` | Плагины на Python, работают мгновенно без перекомпиляции |
| **Смена внешности, неоновые цвета, скругления** | `tdata/plugins/*.py` | Задается прямо в плагине через `__stylesheet__ = """..."""` |
| **Перехват отправки сообщений** | `history_widget.cpp` | Метод `sendTextWithTags()` |
| **Режим призрака и статус в сети** | `api_updates.cpp` | Метод `updateOnline()` |
| **Непрочтение сообщений** | `data_histories.cpp` | Метод `sendReadRequest()` |
| **Анти-удаление сообщений** | `data_session.cpp` | Метод `processMessagesDeleted()` |
| **Метки на сообщениях (`[DELETED]`, `(изменено)`)** | `history_view_bottom_info.cpp` | Метод `layoutDateText()` |
| **Одноразовые фото и видео** | `data_media_types.cpp` | Методы `ttlSeconds()`, `ttlSecondsSingleView()` |
| **Тумблеры и поля ввода в настройках** | `settings_privacy_security.cpp` | Конструктор `SectionBuilder` |
| **Сохранение новых настроек в профиле** | `Core::App().settings()` | `readPref<Type>()` и `writePref<Type>()` |

## 💡 3 золотых правила Vibe-кодера в Tawagram

1. **Пиши лёгкие фичи плагинами, а не в ядре C++**:
   Если тебе нужна команда, автопереводчик, очистка ссылок или кастомная тема — напиши `.py` файл и кинь в `tdata/plugins/`. Это работает мгновенно и не требует сборки проекта.
2. **Никогда не трогай бинарный `QDataStream` настроек**:
   Всегда говори нейронке: *«Сохраняй настройку через `Core::App().settings().writePref`»*. Это защитит твой профиль от повреждения при обновлениях.
3. **Сохраняй файлы с нормальными переносами строк**:
   В Windows файлы должны быть с переносами строк **CRLF** и в кодировке **UTF-8 без BOM**.

## 🎯 Готовые промпты для нейронки (Копируй и отправляй)

### Промпт 1: Сделай плагин для темы
> *"Напиши для Tawagram Python-плагин оформления, который делает интерфейс в фиолетовых тонах (как в Discord/Dracula), скругляет все поля ввода на 12px и делает скроллбары полупрозрачными."*

### Промпт 2: Сделай плагин с крутыми командами
> *"Сделай Python-плагин для Tawagram, который заменяет команды:  
> `.shrug` на ¯\\_(ツ)_/¯  
> `.flip` на (╯°□°)╯︵ ┻━┻  
> `.dis` на ( ͡° ʖ̯ ͡°)  
> `.time` на текущее московское время."*

### Промпт 3: Добавь новую фичу прямо в движок C++
> *"Добавь в настройки Tawagram тумблер 'Блокировать анимацию реакций на сообщениях'. Сохраняй состояние через `readPref<bool>('disable_reactions_anim', false)` и отключай воспроизведение в коде."*

## 🛠️ Как запустить свой плагин за 30 секунд:

1. Открой Tawagram.
2. Зайди в **Настройки → Конфиденциальность → Плагины (Tawagram Plugins)**.
3. Нажми кнопку **«Открыть папку с плагинами»**.
4. Создай там файл `my_plugin.py` или вставь код от нейронки.
5. Нажми в приложении **«Перезагрузить плагины»** — и всё готово, фича уже работает!
